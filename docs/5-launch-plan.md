# Go-To-Market & Launch Checklist

## Marketing & User Acquisition

*   **Primary Launch Channel:** Campus outreach for the first 50 users: flyers with a QR code in the library and study spaces, plus posts in class group chats and student subreddits such as r/college and r/studytips.
*   **Value Proposition:** GrowFocus is a free study app that keeps you on task by adding time every time you get distracted, so you finish the study session you planned.

## Pre-Launch Deployment Checklist

- [ ] Verify all code changes are merged into the `main` production branch
- [ ] Test that tab-switch detection correctly adds time to a session
- [ ] Test the study material input (empty input, very long text, special characters)
- [ ] Test the session timer (start, finish, and refresh mid-session)
- [ ] Run a cross-browser usability check (Chrome, Safari, mobile screens)
- [ ] Confirm the site clearly explains what it detects, and that no study material leaves the browser

## Launch Day Operations

- [ ] Trigger the final deployment and check the live production URL
- [ ] Run a full study session directly on the hosted site
- [ ] Post the announcement across the primary marketing channels
- [ ] Put up the QR-code flyers on campus
- [ ] Collect feedback from the first users (short form or comment thread)
